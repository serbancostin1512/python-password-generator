
# Python Password Generator

A simple command-line password generator built with Python.

## Features

- Generate random passwords with a custom length
- Optionally include digits
- Optionally include symbols
- Validate user input
- Use Python's `secrets` module for secure random selection

## Requirements

- Python 3

No external packages are required.

## How to Run

Clone the repository or download the source code.

Run the application from your terminal:

```bash
python password_generator.py
```

Enter the desired password length and choose whether to include digits and symbols.
